LibKa — Verification

This page recomputes every accessibility claim in the browser from the token values that the build writes into this page from tokens/*.tokens.json. Nothing here is asserted by hand — open it, read the numbers. Toggle the theme to confirm both modes.

1 · Token reference resolution

Every component/icon/viz token that uses ref must point at a value that exists. A broken chain fails the build.

2 · Contrast matrix — light theme

Normal text needs 4.5:1 (WCAG 2.2 AA). UI / large text / focus ring need 3:1.

3 · Contrast matrix — dark theme

4 · Colorblind distinguishability (viz series)

CIE76 ΔE between every series pair under simulated deuteranopia, protanopia and tritanopia. Threshold: ΔE ≥ 15. Below that, pairs are too similar and pattern fills become mandatory.
